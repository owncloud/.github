This is the GitHub organization-level configuration repository for ownCloud. It hosts the default community health files, GitHub Actions workflows, and the organization profile page displayed on the [ownCloud GitHub organization](https://github.com/owncloud). The `profile/` directory contains the content rendered on the organization's public landing page.

## Part of Community / Meta

This repository provides organization-wide defaults and shared configurations for all repositories under the [owncloud](https://github.com/owncloud) GitHub organization. It follows GitHub's conventions for [creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Getting Started

This repository does not contain runnable software. To modify the ownCloud GitHub organization profile, edit the files in the `profile/` directory. Community health files placed here (e.g., `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`) serve as defaults for all repositories that do not provide their own.

### Workflow

- **Rebase Early, Rebase Often!** We use a rebase workflow. Always rebase on the target branch before submitting a PR.
- **Dependabot**: Automated dependency updates are managed via Dependabot. Review and merge dependency PRs promptly.
- **Signed Commits**: All commits **must** be PGP/GPG signed. See [GitHub's signing guide](https://docs.github.com/en/authentication/managing-commit-signature-verification).
- **DCO Sign-off**: Every commit must carry a `Signed-off-by` line:
  ```
  git commit -s -S -m "your commit message"
  ```
- **GitHub Actions Policy**: Workflows may only use actions that are (a) owned by `owncloud`, (b) created by GitHub (`actions/*`), or (c) verified in the GitHub Marketplace.
